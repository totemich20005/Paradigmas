Calculadora de Promedio de Notas

Programa desarrollado en Python utilizando programación imperativa. El programa permite ingresar varias notas, calcular el promedio del estudiante y determinar si aprobó o reprobó según una nota mínima de 3.0.

Objetivo
El objetivo de este proyecto es practicar conceptos básicos de programación imperativa en Python, como:

Variables
Entrada de datos con input()
Conversión de tipos con int() y float()
Ciclos for
Operadores aritméticos
Condicionales if y else
Salida de información con print()
 ¿Cómo funciona?
El programa realiza los siguientes pasos:

Solicita al usuario la cantidad de notas que desea ingresar.
Pide cada una de las notas mediante un ciclo for.
Suma todas las notas ingresadas.
Calcula el promedio.
Muestra el promedio obtenido.
Determina si el estudiante aprobó o reprobó:
Promedio ≥ 3.0: APROBÓ 
Promedio < 3.0: REPROBÓ
